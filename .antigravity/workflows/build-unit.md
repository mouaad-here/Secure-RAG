# Title: Build a Project Unit
# Description: Executes one scoped unit with full context awareness.

Step 1: Read the Six-File Context Skill and all six context files.
Step 2: Read the unit spec from `.ai-context/specs/{unit-name}.md`.
Step 3: Mark the unit as IN PROGRESS in PROGRESS_TRACKER.md.
Step 4: Generate an Implementation Plan Artifact. List every file to create/modify and the exact changes.
Step 5: PAUSE and wait for human approval of the Implementation Plan.
Step 6: After approval, execute the plan file by file.
Step 7: Run type-check, lint, and any relevant tests.
Step 8: Launch the dev server and open the integrated browser to verify UI/functionality.
Step 9: Capture screenshots and browser recordings as Verification Artifacts.
Step 10: Mark the unit as COMPLETE in PROGRESS_TRACKER.md.
Step 11: Produce a Walkthrough Artifact summarizing what was built and how to verify it.
